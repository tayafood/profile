# TAYA FOOD - Company Profile Website

Website hồ sơ năng lực của **Công ty TNHH Thực Phẩm TAYA Việt Nam**.

## 🌐 Đa ngôn ngữ

Website hỗ trợ 6 ngôn ngữ:
- 🇻🇳 Tiếng Việt
- 🇺🇸 English
- 🇨🇳 简体中文
- 🇯🇵 日本語
- 🇰🇷 한국어
- 🇹🇭 ภาษาไทย

## 📁 Cấu trúc thư mục

```
profile/
├── index.html              # Trang chính
├── privacy.html            # Chính sách bảo mật
├── robots.txt              # Hướng dẫn cho search engines
├── sitemap.xml             # Sitemap cho SEO
├── asset/
│   ├── favicon.png
│   ├── TAYAFOOD_PROFILE.pdf
│   ├── images/             # Hình ảnh
│   └── js/
│       ├── main.js         # Logic chính
│       ├── seo-config.js   # Cấu hình SEO
│       └── i18n/           # File ngôn ngữ
│           ├── vi.js
│           ├── en.js
│           ├── zh.js
│           ├── ja.js
│           ├── ko.js
│           └── th.js
└── .github/
    └── workflows/
        └── static.yml      # GitHub Actions auto-deploy
```

## 🚀 Deploy

Website tự động deploy lên GitHub Pages khi push code lên branch `main` hoặc `master`.
